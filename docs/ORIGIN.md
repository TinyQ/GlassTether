# Source and publication status

This independent baseline contains selected user-owned demo sources and tests only. Source hashes and commit are recorded in PROVENANCE.json. No source Git history, private handoff documents, captured media, device identifiers, or credentials were imported.

CoreMediaIODeviceDiscovery was adapted in the source demo from the user’s LiveMate project. Ownership and any upstream obligations must be confirmed before publication. Other copied modules implement the demo’s mouse transport, USB preview and UI. The source demo reports research into darwin-bt-remote (AGPL-3.0-only), microbit-pxt-blehid, ESP32-BLE-Abs-Mouse and UniControlHub, without importing their source or dependencies. This is a provenance statement based on the handoff, not a clean-room certification.

No open-source license is granted by this draft repository yet. Public release requires owner confirmation of redistribution rights and license choice. Apple frameworks are SDK/system dependencies, not bundled third-party code. Swift Package Manager dependencies: none.

# 安装、配对与恢复

在仓库按 README 构建后，在 Finder 打开新生成的编号应用。应用不会自动安装或启动。当前是本机临时签名包，尚未公证，不作为面向普通用户的公开安装包。

## 连接

先断开其他应用的 iPhone 预览，并停止其他蓝牙鼠标广播。使用支持数据的 USB 线连接一台手机，解锁并信任此 Mac。点击 Connect USB video，相机权限用于 AVFoundation 的 USB 视频；没有音频采集或保存画面。

点击 Pair Bluetooth mouse，在 iPhone 设置 → 辅助功能 → 触控 → 辅助触控 → 设备 → 蓝牙设备，选择 GT Mouse（也可能显示 Mac 名称）。开启辅助触控，关闭停留控制与拖移锁定。自行核对蓝牙手机和 USB 画面是同一台设备，再开启 Control iPhone。

移入真实画面后使用鼠标；左右黑边不操作。右键、中键动作由手机辅助触控配置决定。以手机实际指针位置为准，如果预览不显示手机指针，先停止控制。

## 退出与恢复

移出画面释放按键、恢复 Mac 光标；Esc 停用控制。失焦、休眠、画面超过 0.6 秒没有新帧、蓝牙断线或关闭窗口都会触发保护，恢复后需手动开启控制。计时依赖主线程，不是实时系统保证。蓝牙已断开时无法保证释放报告送达；如手机仍在拖动，请在手机断开鼠标并检查拖移锁定。

- 找不到手机：检查数据线、解锁和信任，关闭其他应用预览，点击 Retry video connection。
- 多台设备：仅保留目标手机后重试。
- 权限拒绝：在 Mac 系统设置 → 隐私与安全性允许 GlassTether 使用相机/蓝牙，再重连；系统要求时重启应用。
- 蓝牙不可见：停止蓝牙，在 Connection details 选择 Compatibility 后重新开始。
- 配对缓存：更改报告格式后，可能需要在手机忘记旧配对再配对。只改名字不能保证清除缓存。
- 已订阅但指针不正确：关闭控制，记录机型和系统版本，提交可复现步骤；订阅成功不等于绝对坐标支持。

本应用不自动移除旧配对，也不修改手机辅助触控设置。

# Proposed license — owner decision required

Recommendation: MIT for a small reusable native utility, if the owner confirms the copied user-owned code can be redistributed. MIT allows broad reuse subject to retaining its notice; its text is short and widely recognized. It does not require recipients to publish modifications. If an explicit patent grant or reciprocal source-sharing is desired, evaluate Apache-2.0 or a copyleft license instead before deciding.

Reference: [OSI MIT license text](https://opensource.org/license/mit). This recommendation is a project governance choice, not verification of rights in upstream code.

Do not add a root LICENSE granting rights until the owner approves. The proposed license file would contain the standard MIT text from the reference, with the verified copyright year and actual copyright holder supplied by the owner. That holder has not been inferred from a machine account.

Before applying it: confirm LiveMate-derived USB discovery ownership and upstream obligations; inspect all imported files against PROVENANCE.json; confirm research did not result in unrecorded third-party code copying; record any required notices. Framework use does not make this an Apple product. Resolve Bluetooth prototype identity separately before distribution.

No root LICENSE exists in this draft. A public GitHub repository without an explicit license is not a completed open-source release.

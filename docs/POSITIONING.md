# Positioning and name review

Research checked 2026-09-10; recheck immediately before public copy is finalized.

| Project | Verified focus | Relevant distinction |
| --- | --- | --- |
| [Apple iPhone Mirroring](https://support.apple.com/en-us/120421) | Wireless interaction, notifications and system integrations; locked nearby phone, same Apple Account, macOS 15+ and iOS 18+ with hardware requirements | GlassTether uses wired video and an AssistiveTouch pointer. No claim that it bypasses regional/system restrictions or supports all older hardware. |
| [darwin-bt-remote](https://github.com/jqssun/darwin-bt-remote) | Bluetooth HID keyboard, relative mouse and media remote; AGPL-3.0-only | GlassTether focuses on video-area absolute pointer mapping, not a general remote. No code imported according to source provenance; technical research occurred. |
| [scrcpy](https://github.com/Genymobile/scrcpy) | Android display/control over USB or TCP/IP | A useful interaction reference, not evidence of iPhone compatibility. No source imported. |

Recommended description: “Native macOS app for wired iPhone video and Bluetooth absolute mouse control. Experimental, local, and explicit.” Avoid “zero latency”, “all iPhones”, “first”, “scrcpy for iOS” or guaranteed parity with Apple's app.

## Shortlist

- **GlassTether**: preferred working name, evokes video plus a cable. Exact-name web search found no results in this check. This is not exhaustive GitHub, domain, app-store or trademark clearance.
- **PalmBridge**: short and pronounceable, but [PalmBridge](https://arxiv.org/abs/2601.20351) already names a palmprint research project. Avoid confusion.
- **CableGlide**: conveys cable and motion, but exact-name searches found existing cable-related commercial uses including [Cableglide](https://www.itwcp.de/tl_files/downloads/downloads/ITW_Cramolin_Selektor_EN_NEW.pdf). Do not choose without further review.

No name is reserved. Confirm owner choice and check the exact desired GitHub owner/repository and relevant naming rights before publication. Bundle ID and Bluetooth identity are development placeholders until then.
